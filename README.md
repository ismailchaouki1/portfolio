# Frontend Portfolio

A personal portfolio built with React + Vite (JSX) and Laravel backend.

## Local Development

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Tech Stack

- **Frontend**: React + Vite, GSAP, CSS Modules
- **Backend**: Laravel 13, MySQL, Node.js/Express
- **Deployment**: Git, npm
