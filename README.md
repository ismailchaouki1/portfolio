## Frontend Design Rules

To prevent generic AI defaults and ensure intentional design decisions:

1. **No eyebrow labels above every section** – Skip small-caps section headers like "SECTION LABEL" unless genuinely needed
2. **No identical 3-card feature rows** – Each section with cards should have unique visual structure based on content
3. **No gradient text or glassmorphism as default** – Use solid colors or subtle textures instead
4. **No generic AI-purple/blue gradients** – Stick to the intentional palette: dark blue/charcoal base with amber accent
5. **Every visual choice must be intentional** – Each UI element should serve a specific purpose, not follow AI patterns
