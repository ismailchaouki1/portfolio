# Frontend Portfolio

A personal portfolio built with React + Vite (JSX) and Laravel backend.

## Features

- Responsive design with design system tokens
- Navigation with active state
- Content structured with modular components
- GSAP for animations
- Modern CSS with accessibility best practices

## Local Development

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Files Structure

- `src/components/` – Reusable React components
- `src/styles/` – CSS modules and design tokens
- `src/content.js` – Portfolio data
- `src/utils.js` – Shared helper functions

## Tech Stack

- React + Vite (JSX)
- GSAP
- CSS (modules + design tokens)
- Node.js
- Git
